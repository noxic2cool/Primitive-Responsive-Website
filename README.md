# Primitive Responsive Website v1
A very simple responsive website that will be getting more complex as time goes on.

Initial creation is for both mobile-first responsive sites and to become more consistent using Git and GitHub.

For the mobile-first responsive website, I practiced using flexbox to make the nav links responsive to different screen sizes, first checking mobile sizes, then desktop sizes. More sizes (different phone sizes and tablet) to be added in the future. Positioning was also used to ensure the nav stayed at the top of the screen at all times.
